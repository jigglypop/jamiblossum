# 유료 해석 서비스 준비 경계

현재 웹은 `jamiblossom` 패키지를 소비해 무료 만세력과 자미두수 원국을 브라우저 안에서 계산한다. 유료 카드에는 결제나 AI 요청을 연결하지 않았으며 실제 운영 자격 증명 전에는 계속 `준비 중`으로 표시한다.

유료 백엔드는 아직 구현되지 않았다. 구현 계획은 API Gateway → Lambda 순서로 요청을 받고, Lambda가 결제사의 서명된 webhook과 주문 상태를 서버에서 확인한 뒤에만 원국 JSON, 상품 유형, 사용자 질문을 서버 전용 프롬프트와 조합하는 것이다. AI 키와 상세 프롬프트는 Secrets Manager에 두고 브라우저 번들, npm 패키지, 로그에 포함하지 않는다. 응답은 주문 소유자만 읽을 수 있는 짧은 만료 URL 또는 인증 API로 전달한다.

첫 상품은 건별 `상세 프롬프트 + AI 해석`을 기본으로 한다. 사주, 자미두수, 궁합, 맹파 관점 네 종류를 제공하되 맹파는 자미블로썸의 제품 해석 프레임이라고 명시한다. 맹파 템플릿은 원전 검토와 현업 전문가 감수 전 초안이며 그 전에는 유료 상품으로 활성화하지 않는다. 결제 전 예상 결과 목차와 환불 조건을 보여 주고 결제 성공 상태를 클라이언트 값만으로 신뢰하지 않는다.

비용 효율은 모델 가격을 가정해 주장하지 않고 실제 사용량으로 측정한다. 요청마다 입력·출력 토큰, 지연, 재시도, 모델, 캐시 적중, 주문 매출을 기록하되 출생 정보와 질문 본문은 지표 로그에서 제외한다. 상품별 최대 토큰과 1회 재시도 한도를 둔다. 캐시 키는 소유자·주문·상품·프롬프트 버전·모델·정규화한 질문과 원국을 HMAC으로 묶어 개인정보를 노출하지 않으며, 캐시 적중 때도 주문 소유권을 다시 확인한다. `주문당 AI 비용`, `완료율`, `환불률`, `p95 지연`과 함께 `순마진 = 매출 - 결제 수수료 - 세금 및 환불 충당 - 모델 비용 - 인프라 비용`을 측정해 모델과 컨텍스트 길이를 조정한다. 출시 전 수익이나 절감 수치를 보장하지 않는다.

출시 게이트는 결제사 계정·상품·webhook, AI 공급자 키, 개인정보 및 환불 문구, 주문 저장소와 보존 기간, 악용 방지, 프롬프트 회귀 평가, 오류 시 자동 환불 또는 재처리 정책의 실제 연결이다.
