# 만세력 화면 비교와 설계 결정

2026-09-19 기준 공개 페이지를 비교했다. 로그인·생년정보 제출 뒤에만 보이는 결과는 직접 관찰했다고 기록하지 않았다.

## 관찰한 제품

- [척척만세력](https://sajuplus.com/cheokcheok-calendar)과 [공식 사용 가이드](https://sajuplus.com/cheokcheok-calendar-guide): 결과 예시와 공식 설명에서 `시주 → 일주 → 월주 → 년주` 열, 큰 천간·지지, 일주 우선 안내, 오행 분포와 대운·세운의 단계적 확인을 명시한다. 실제 조회 화면은 입력 제출이 필요해 공개 가이드의 결과 이미지·설명을 근거로 삼았다.
- [사주티아이 무료 만세력](https://sajuti.kr/sj4c/ms/msA1.php): 공개 화면에서 오늘의 년주·월주·일주와 오행을 먼저 보여 주고, 절입일에는 시각에 따라 월주가 달라질 수 있음을 안내한다. 명식 입력 결과의 전체 표는 제출 전에는 관찰하지 않았다.
- [ManseFlow](https://www.manseflow.com/): 공식 제품 페이지는 원국, 오행, 십신, 공망, 대운과 세운을 한 흐름으로 정리한다고 설명한다. 공개 소개 범위를 넘어선 결과 배치는 추정하지 않았다.
- [툴잼 무료 만세력](https://tooljam.kr/manseryeok): 공식 페이지는 년·월·일·시 네 기둥과 일간, 십성, 오행 분포, 지장간을 함께 제공한다고 밝힌다. 결과 화면의 세부 배치는 입력 없이 확인하지 못했다.

## 자미블로썸 설계 결정

1. 전통적인 `시·일·월·년` 열과 고정 행 라벨을 사용한다. 일주를 읽는 기준으로 삼되 네 기둥을 같은 표 안에서 비교할 수 있게 한다.
2. 천간·지지는 가장 크게, 오행별 색은 의미 구분에만 사용한다. 십성·지장간·12운성·공망·납음은 좁은 보조 행으로 둔다.
3. 원국 보조 정보와 대운은 표 아래 단계로 분리한다. 대운은 실제 절입 시각 경계를 표시하고 현재 항목만 강조한다.
4. 운 기준 날짜·시각을 사용자가 바꾸면 WASM worker가 다시 계산한다. 신강약, 용신 점수, 신살처럼 현재 엔진에 검증된 규칙이 없는 값은 만들지 않는다.
5. 척척만세력의 정보 순서는 참고하지만 시각 스타일은 복제하지 않는다. 자미블로썸은 따뜻한 미색, 잉크색, 저채도 자주·더스티 체리과 직선형 표를 사용한다.

## 현재 계산 경계

출생 시각은 한국 표준시에서 고정 30분을 앞당기는 기존 제품 규칙을 사용한다. 해외 출생지의 경도, 역사적 표준시와 서머타임을 일반화해 보정하지 않는다. 따라서 화면에 이 가정을 명시하며, 지원하지 않는 보정을 실제 진태양시처럼 표현하지 않는다.
